# Snug

One shared space for the two of you: groceries, calendar, and more.

## Run it on your computer
1. Install [Node.js](https://nodejs.org) (version 20 or newer).
2. In a terminal, inside this folder:
   ```bash
   npm install
   npm run dev
   ```
3. Open http://localhost:3000. Make the browser window narrow, or use your browser's
   phone view (DevTools → device toolbar), to see the mobile layout.

See `CLAUDE.md` for the project conventions and build progress.
