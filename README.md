# Snug

One shared space for the two of you: groceries, calendar, and more.

**Live app:** https://snug-eta.vercel.app

## Put it on your phone
- **iPhone:** open the link in Safari → tap Share (square with an arrow) → **Add to Home Screen**.
- **Android:** open the link in Chrome → tap **Add to home screen** on Snug's home card
  (or ⋮ menu → Install app).

## Run it on your computer
1. Install [Node.js](https://nodejs.org) (version 20 or newer).
2. Copy `.env.example` to `.env.local` and fill in your Supabase URL and anon key.
3. In a terminal, inside this folder:
   ```bash
   npm install
   npm run dev
   ```
4. Open http://localhost:3000. Make the browser window narrow, or use your browser's
   phone view (DevTools → device toolbar), to see the mobile layout.

See `CLAUDE.md` for the project conventions and build progress.
